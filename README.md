# Landing de Consultorio de Dermatología

Landing page demo para un consultorio de dermatología, desarrollada como pieza de portafolio para Vegora.

## Qué resuelve

Presenta servicios dermatológicos y facilita el agendamiento de citas desde el sitio.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS

## Estado

Demo de portafolio.
